帛书 0.2.3：标签页、补全与界面动效

- 仅有一个标签页时隐藏关闭按钮；有未保存内容时仍显示圆点提示。新增第二个标签后恢复关闭按钮。
- 输入纯数字时不再弹出补全，补全候选也会排除纯数字；`name2`、`var123` 等带数字的名称仍可正常补全。
- 菜单、更新面板、命令面板、确认框、搜索及补全气泡加入轻量动效，工具栏和路径提示采用跟随主题的气泡。
- 新增、关闭标签页及相邻标签移动更顺滑；输入文字、切换标签和下载进度更新不会反复触发入场动画。
- 动画尊重系统的“减少动态效果”偏好；关闭浮层立即释放操作和键盘焦点，快速连续打开、关闭也不会残留遮挡。

继续提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包，以及签名后台更新。安装更新仍需用户点击确认。从 0.1.x 升级请手动运行安装包。

macOS 安装包使用临时签名，尚未经过 Apple 公证。请将应用放入 Applications 后使用应用内更新。
