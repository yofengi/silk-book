帛书 0.2.2：启动空白文档与文件拖放

- 启动后直接提供可输入、可保存的未命名标签页；启动时打开文件或移入标签页时，不额外保留空白标签。
- 将文件拖到正文区时，复用尚未修改的空白未命名标签；当前标签已有内容时，在其后插入新标签，保留原文。
- 将文件拖到标签栏时，显示跟随主题的插入线，按落点打开文件；悬停边缘可横向滚动标签栏，多文件保持拖入顺序。
- 文件读取期间继续编辑时，不会用读取结果覆盖新输入的内容；读取失败也不会删除已有文稿。
- 继续提供签名后台更新，以及 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包；安装更新仍需用户点击确认。

0.2.0、0.2.1 用户可通过应用内更新下载本次版本；安装需要点击确认。从 0.1.x 升级请手动运行安装包。

macOS 安装包使用临时签名，尚未经过 Apple 公证。请将应用放入 Applications 后使用应用内更新。
