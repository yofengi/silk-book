帛书 0.2.0：后台下载与应用内更新

- 更新包在后台下载，关于页和顶栏同步显示进度，关闭弹窗后继续下载。
- 关于页新增“自动更新”开关，默认关闭。开启后自动下载，安装仍需点击确认。
- 手动更新可选择“仅下载”或“下载并安装”。后者下载完成后弹出“安装并重启”，等待用户点击。
- 下载完成后显示安装按钮；安装前等待正在进行的文件保存，再检查所有窗口的未保存内容，取消后继续编辑。
- 下载包经过签名及版本验证，重启应用后保留已验证的安装包；升级成功后清理应用自己的更新缓存。
- 支持 Windows x64、macOS Apple Silicon 和 Intel 的更新包；继续提供常规 EXE/DMG 安装包。

从 0.1.x 升级时，请先下载并运行本次安装包。安装 0.2.0 后，后续版本可通过应用内后台下载更新。

macOS 安装包使用临时签名，尚未经过 Apple 公证。下载的应用如被系统拦截，可在系统“隐私与安全性”中允许打开；请将应用放入 Applications 后使用应用内更新。
